# AI 快讯桌面悬浮窗

一个面向 Windows 11 x64 的常驻桌面新闻小组件。它从 Google News RSS 和 Bing News RSS 聚合中英文 AI 新闻，不需要账号、API Key 或单独安装 Node.js。

## 安装与使用

1. 运行 `release` 目录中的 `AI快讯-安装程序-1.1.0-x64.exe`。
2. 完成安装后启动“AI快讯”。首次运行会立即获取最新动态并回补最近一个完整周。
3. 点击任意标题会使用 Windows 默认浏览器打开原报道。
4. 点击窗口右上角 `×` 只会隐藏到系统托盘；右键托盘图标并选择“彻底退出”才能停止后台运行。
5. 应用默认随 Windows 登录启动。可以在窗口底部或托盘菜单中关闭该设置。

窗口默认大小为 280×360，可以从边缘或右下角自由调整宽高，位置和大小会自动记忆。窗口达到 520 像素宽时，周报与最新动态会自动切换为双栏；折叠按钮会把窗口收成一条 64 像素高的状态栏。

标题栏的齿轮按钮可以打开设置：

- 选择中英混合、中文或英文新闻；中文模式优先显示官媒和官方发布来源。
- 自定义背景色、强调色以及 60%–100% 的背景透明度。
- 恢复跟随系统深浅色、默认外观或默认窗口大小。

## 更新规则

- 最新动态：启动时立即刷新，成功后每两小时刷新一次；失败时按 5、15、30 分钟退避重试。
- 上周大事件：按系统本地时区统计上周一 00:00 至本周一 00:00，并在周一 12:00 更新。
- 若周一中午电脑处于关机或休眠状态，应用恢复后会补执行。
- 新闻源不可用时不会清空界面，而是保留最后一次成功缓存并显示状态提示。
- 缓存只保留最近 60 天，位于 Electron 的 Windows `userData` 目录。

“一句话摘要”即新闻源提供的原始标题；中文和英文均保留原文，不使用自动翻译或生成式 AI。官媒和官方账号会显示对应徽标，来源数量不足时再以普通新闻媒体补足。

## 本地开发

需要 Node.js 22 或更高版本以及 pnpm。

```powershell
pnpm install
pnpm dev
```

常用验证命令：

```powershell
pnpm typecheck
pnpm test
pnpm build:app
pnpm build
```

`pnpm build` 会在 `release` 中生成 Windows x64 NSIS 安装程序。

## 隐私与安全

- 应用不收集账户信息或遥测数据。
- 本地仅保存标题、报道链接、媒体名、发布时间、抓取时间和用于去重的指纹。
- 不复制或存储新闻正文。
- 渲染进程禁用 Node.js 集成，只能调用预先定义的 IPC 接口。
- 外部链接仅允许 `http` 和 `https` 协议，并交给系统默认浏览器处理。
